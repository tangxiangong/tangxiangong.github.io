# 我的第一篇文章

欢迎来到我的个人博客！这是我使用 Rspress 搭建博客后的第一篇文章。

## 为什么选择 Rspress？

Rspress 是一个基于 Rust 的静态站点生成器，具有以下优势：

- 🚀 **极快的构建速度** - 基于 Rust 工具链，构建速度非常快
- 📦 **支持 MDX** - 可以在 Markdown 中使用 React 组件
- 🎨 **现代化设计** - 默认主题美观且易用
- 🔍 **内置全文搜索** - 开箱即用的搜索功能

## 搭建过程

搭建这个博客的过程非常顺利：

1. 使用 Rspress 官方模板初始化项目
2. 配置个人信息和导航菜单
3. 创建博客文章目录结构
4. 部署到 GitHub Pages

整个过程简单高效，让我能够专注于内容创作。
